# 天气预报

一个练习用的最简天气预报网页。纯 HTML / CSS / JavaScript，**没有任何依赖，不需要安装、不需要打包**。

## 怎么用

直接双击 `index.html`，用浏览器打开就能看。在搜索框里输入城市名（例如「北京」「杭州」「成都」），回车即可查询。

## 功能

- 搜索任意城市（中文可搜，支持同名城市选择）
- 显示当前温度、天气状况、体感温度、湿度、风速
- 显示未来 7 天的天气预报

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构（搜索框、当前天气卡片、7 天列表） |
| `style.css` | 页面样式（配色、卡片、响应式布局） |
| `app.js` | 逻辑（调接口、解析数据、渲染页面） |
| `.gitignore` | 告诉 Git 哪些文件不要上传（密钥、依赖、数据库等） |

## 数据来源

[Open-Meteo](https://open-meteo.com/) —— 免费公开的天气接口，**不需要注册、不需要 API 密钥**。

用到两个接口：

- 城市搜索：`https://geocoding-api.open-meteo.com/v1/search`
- 天气数据：`https://api.open-meteo.com/v1/forecast`

## 关于密钥的说明

因为用的是免密钥接口，这个项目目前**没有 `.env`，也没有任何密钥**。

如果以后换成需要密钥的接口（例如和风天气、OpenWeatherMap），请遵守这个规则：

1. 真实密钥放进 `.env` 文件（`.gitignore` 已经把它挡住了，不会上传）
2. 同目录再建一个 `.env.example`，只写占位符，比如 `WEATHER_API_KEY=在这里填你自己的密钥`
3. **绝对不要**把密钥直接写进 `app.js`。这是纯前端项目，源码任何人按 F12 都能看到。真要藏密钥，需要加一层后端来转发请求。
